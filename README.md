# 人生曲线 · Life Trajectory

> 基于「时间精力应投入到生命力天然更旺盛的主体中」这一战略框架的可视化工具

---

## ✨ 功能简介

将人生轨迹图形化，量化分析以下六条关键曲线的叠加效应：

| 曲线 | 说明 |
|------|------|
| **传统就业** | 稳定的线性收入，用作"低保"兜底 |
| **创业脉冲** | 不规则的脉冲尝试，高波动高潜力 |
| **连续创业** | 阶梯式跃升，每个周期后平台上移 |
| **AI 协作** | 跃迁式能力提升，持续复利增长 |
| **资本复利** | 经典指数增长，越早开始越有效 |
| **复合叠加** | 所有曲线的加权合成，理想人生轨迹 |

**核心目标**：复合叠加曲线实现「每个低点都高于前一个低点」—— **永久牛市**

## 🚀 GitHub Pages 部署步骤

### 方法一：直接上传（最简单）

1. 登录 [GitHub](https://github.com)，创建新仓库（Repository）
2. 仓库名填写：`life-curve`（或任意名称）
3. 选择 **Public**（公开）
4. 点击 **Add file → Upload files**，上传 `index.html`
5. 进入仓库 **Settings → Pages**
6. Source 选择 **Deploy from a branch**
7. Branch 选择 **main**，文件夹选 **/ (root)**
8. 点击 **Save**
9. 等待 1-2 分钟后，访问 `https://你的用户名.github.io/life-curve/`

### 方法二：Git 命令行

```bash
# 1. 在项目目录初始化 git
git init
git add index.html README.md
git commit -m "init: life trajectory dashboard"

# 2. 创建 GitHub 仓库后推送
git remote add origin https://github.com/你的用户名/life-curve.git
git branch -M main
git push -u origin main

# 3. 在 GitHub 网页端启用 Pages（Settings → Pages → main branch）
```

## 📱 使用说明

### 左侧面板 — 曲线参数设置

每条曲线都可以：
- **开关切换**：点击右侧开关显示/隐藏曲线
- **参数调节**：展开面板调整关键指标

| 曲线 | 关键参数 |
|------|---------|
| 传统就业 | 工作年龄、巅峰年龄、退休年龄、峰值收入 |
| 创业脉冲 | 开始年龄、尝试次数、成功率、脉冲幅度 |
| 连续创业 | 启动年龄、周期数、周期长度、最终峰值 |
| AI 协作 | 采用年龄、初始跃迁量、协作深度、技能水平 |
| 资本复利 | 开始投资年龄、初始资本、年化收益率、年度追加 |

### 右侧面板 — 个人状态管理

- **当前年龄**：拖动滑块，图表自动更新「当前位置」标记
- **当前阶段**：选择你所处的人生阶段（探索期/成长期/巅峰期等）
- **关键节点预测**：自动计算未来关键年龄的复合指数
- **人生里程碑**：添加、编辑、删除重要事件标记
- **阶段备注**：记录当前的想法、目标和计划

### 顶部状态栏

| 指标 | 说明 |
|------|------|
| 当前年龄 | 你设置的年龄 |
| 阶段 | 当前人生阶段标签 |
| 低点保障 | ✓ 永久牛市 / △ 未达标 |
| 复合指数 | 当前年龄的复合叠加值 |
| 资本曲线 | 当前年龄的资本复利值 |

### 数据管理

| 功能 | 说明 |
|------|------|
| **保存快照** | 保存当前参数和备注到本地（最多30条） |
| **历史快照** | 查看、恢复或删除历史快照 |
| **导出** | 下载 JSON 文件（包含所有参数和快照） |
| **导入** | 从 JSON 文件恢复数据（换设备时使用） |
| **重置** | 恢复所有默认值 |

## 💡 使用建议

### 初次使用

1. 首先设置**当前年龄**
2. 根据你的实际情况调整**传统就业**参数（是否在职、薪资水平）
3. 设置**创业脉冲**参数（你的尝试频率和成功率预期）
4. 设置**AI 协作**（你当前开始使用AI的年龄和深度）
5. 设置**资本复利**（你的储蓄和投资计划）
6. 观察**复合叠加**曲线是否实现「永久牛市」效果

### 定期更新

- **每季度**：保存快照，更新备注
- **重大事件后**：调整对应曲线参数（加薪、创业成功/失败、增加投资等）
- **年底复盘**：对比历史快照，评估人生曲线走向

## 🧠 理论框架

来源：「有趣的图形化人生框架」(2026.4.12)

> **核心洞察**：公司和AI作为主体，天然比人具有更旺盛的生命力——出道即巅峰、自带飞轮和杠杆。人生主线应是把有限时间精力投入到生命力天然更旺盛的主体中（公司/AI），而非仅投入自身。

**五曲线叠加逻辑**：
- 传统就业 → 低保 + 白嫖保险
- 创业脉冲 → 寻找突破机会
- 连续创业 → 阶梯式跃升
- AI协作 → 能力跃迁 + 杠杆放大
- 资本复利 → 抹平波动 + 永久托底

## 技术栈

- **纯静态**：HTML + CSS + JavaScript，无需服务器
- **Chart.js 4.4**：图表渲染
- **chartjs-plugin-annotation**：当前年龄标记线
- **LocalStorage**：数据持久化（数据保存在本地浏览器）
- **Google Fonts**：Playfair Display + Barlow + JetBrains Mono

*All data is stored locally in your browser. No server, no tracking.*
